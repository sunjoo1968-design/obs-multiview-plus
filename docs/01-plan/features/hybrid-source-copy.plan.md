# Hybrid 소스 복제 호환 계획

제작자 SunjooAn. 새 버전 0.5.2 Hybrid를 OBS-Multiview 프로젝트에서 개발하며 기존 0.4.0/0.5.0/0.5.1 릴리스와 현장 설치본을 보존합니다.

목표는 Camera MIX Hybrid의 ME1 소스 복제에서 PGM 카메라 장면·소스 타일 적색, Preview 녹색을 실제 bus별로 표시하는 것입니다. ME2, Source Switcher, 기존 명시적 탈리 소스 UUID 및 레이아웃 설정은 유지합니다. 탈리와 펌웨어를 변경하지 않습니다.

검증 기준: 실제 복제 PGM 출력 사용, 복제본 가시성 유지, 원본 UUID 대응, 두 카메라 실제 타일 색상, 내부 이름 충돌 차단, 기존 레이아웃/전체 UI/렌더링 검사, 반복 조회 자원 회수, 정상 종료, 새 Windows x64 패키지.

사용량이 소진되면 체크포인트를 보존하고 리셋 후 자동 확인으로 재개합니다. 리셋 크레딧이나 유료 추가 사용은 자동 소비하지 않습니다. 완료하면 후속 확인을 중지합니다.
